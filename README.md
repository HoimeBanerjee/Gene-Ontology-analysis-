# Gene-Ontology-analysis-
Gene Ontology analysis for miR targets using R.

# Logic and representation

1. Cutoff Values Used & Statistical LogicThreshold applied:Primary Cutoff: Nominal $p$-value $< 0.05$ (Over-Representation Analysis via Hypergeometric/Fisher’s Exact Test).   Redundancy Cutoff: GO Semantic Similarity threshold = $0.7$ (via clusterProfiler::simplify()).   Statistical & Biological Logic:Selection of Nominal $p$-value ($p < 0.05$):In target analysis of specific microRNAs (miRNAs), target gene sets are typically small and highly focused (e.g., 10–30 genes). Applying overly stringent multiple-testing corrections—such as Benjamini-Hochberg (BH) False Discovery Rate (FDR)—across thousands of Gene Ontology (GO) terms can over-penalize small gene lists, causing genuine biological signals to be lost (type II errors). Filtering by a nominal $p$-value threshold ($p < 0.05$) retains biologically relevant target pathways while ensuring that categories included in the analysis exhibit statistically significant over-representation beyond random expectation.   Semantic Similarity Filtering ($0.7$ Cutoff):Gene Ontology operates as a Directed Acyclic Graph (DAG), where child terms inherit gene annotations from parent terms. When a miRNA targets key regulatory hub genes (such as phactr4b or sema4c), those same genes repeatedly trigger significance across multiple hierarchically linked categories (e.g., neural crest cell migration, mesenchymal cell migration, and neural crest cell development). Collapsing terms at a semantic similarity threshold of $0.7$ eliminates redundant parent/child pathways, preserving only distinct functional clusters.   

2. Why This Visual Representation Is IdealThis custom horizontal bar plot design addresses key aesthetic and technical challenges common in enrichment visualizations:   Dual Annotation (Count + Gene Symbols + Exact $p$-values):Unlike standard dot plots or basic bar charts that only display category descriptions, this layout explicitly maps each cluster's exact gene count, mapped zebrafish gene symbols (e.g., [phactr4b, sema4c]), and nominal $p$-value directly next to each bar on a single line.   Significance-Based Sorting:Ranking categories from top to bottom by statistical significance (lowest $p$-value at top) ensures that the most robust biological processes immediately draw reviewer attention, matching the continuous red-to-blue color gradient.   Extended Grid Canvas ($0–5$ Axis Range):Expanding the x-axis grid to $5$ provides internal margin space inside the plot area, preventing long gene lists and text annotations from overflowing or overlapping with the color scale legend.   

3. How This Representation Is UsefulPublication-Ready Transparency:Reviewers and readers can immediately verify which specific genes drive the statistical enrichment of each pathway without cross-referencing supplementary tables.   Clear Biological Storytelling:Removing hierarchical GO redundancy prevents clutter, allowing researchers to quickly discern the broad biological processes (e.g., neural tube formation vs. calcium signaling) regulated by downregulated miRNA targets.   Reproducibility & Audit Trail:The pairing of this plot with the three-tab Excel workbook (Down reg analysis.xlsx containing Overview, Enriched Clusters, and Excluded Clusters) ensures complete reporting compliance for publication standards
